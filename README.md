
# Dashboard

Le Dashboard est un projet Web de la Tech3

Il consiste à réaliser un tableau de bord avec de nombreux widget




## Deployment

```bash
  npm start
```


## Tech Stack

**Front**: Angular 22

**Back**: Django

**Database**: Sqlite 3
